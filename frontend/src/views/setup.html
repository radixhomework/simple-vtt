Welcome! This is the first start of your Simple VTT instance. Set up an administrator account, or bring the data of a previous instance back by importing a backup.

If an environment-configured admin already exists (ADMIN_USERNAME / ADMIN_PASSWORD), submitting those credentials adopts it.

The backup replaces everything on this instance (users, maps, settings and — for local storage — all uploaded files). The server restarts when the import completes; this page follows the progress and opens the login page when the restore is done.
